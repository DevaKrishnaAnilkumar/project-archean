# C10 raw evidence format

`design.csv` maps every world directory to its fixed setting, seed and arm. Binary arrays are packed little-endian. `founders.bin` u8 genotypes in ID order. `mapping.bin` 240 u8 true mapping states. `actions.bin` uses C08 packed 30-byte Step schema (see C08 model and audit). `events.bin` uses C08 7-byte Event schema; parent=65535 denotes death. `births.bin` packed 38 bytes: t,id,p1,p2 (u16 each); pre,gt (u8 each); debit1,debit2 (u16 each); p1belief,p2belief,child (float64 each). p2=65535 for single-parent; its belief placeholder .5, debit zero. `periods.bin` packed 20 bytes: eligible,births,unpaired,blocked (u16 each) then six genotype counts (u16). Unpaired is odd eligible count in paired arms before cap; blocked is potential births minus births after cap. ID unique within world; newborns act next period. Recombination uses two draws in explicit L then S order from stream 14. `audit.py` independently replays all action RNG, posterior/energy transitions, founder/mapping schedules, parent shuffles, birth mutations and recombination, and counts. Evaluation archives include complete raw arrays and audit summaries.
