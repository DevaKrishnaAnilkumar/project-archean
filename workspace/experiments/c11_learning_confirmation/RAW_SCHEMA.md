# C11 raw and audited schemas
Raw files exactly use C08 RAW_SCHEMA.md; Study B has fixed genotypes 2/5 and only mixed populations receive eight replays. C11 design.csv records study, phase, condition, seed, exact settings, founder composition, mutation probabilities and replay count. Each world's raw files independently audited. curves.npy shape (world, period, 13): six end-period genotype counts, founder lineage count, six summed passive counts (zero placeholders when replay count=0; never used as actual replay). accounting.npy shape (world, period, 73): six before-period genotype counts, six death counts, six births by parent genotype, six births by child genotype, 36 parent-to-child transitions row-major, six eligible counts, six eligible-minus-birth blocked counts, one available slot count after death. All rows ordered by audit/worlds.csv. Per-world genotype exposure includes terminal actions; C08 raw actions allow reconstruction of longevity and energy paths. B1/B2 replay quantities undefined (NaN). End-period extinction index zero-based, 240 means censored at horizon. Primary values stored as fractions, convert to pp by multiplying 100. Secondary intervals descriptive and not bounded probability confidence intervals. Plot extinction at period k as fraction with zero-based extinction index >= k. No pooling across study arms or treating replay as independent world.
